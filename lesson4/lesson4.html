HOW MACHINES LEARN AND THINK
Lesson 4
BIAS
Introduction

Here, we add BIAS to the NEURON. So the brain will have two PARAMETERS: WEIGHT and BIAS.

During TRAINING, in each LESSON, these two PARAMETERS will compete for the largest CHANGE.

To see this competition more clearly, let's set PACE to 1.0:

PACE = 1.0
Brain

We're going to build a machine brain that can convert Celsius temperatures to Fahrenheit temperatures.

In this scenario, the INPUT represents Celsius and the OUTPUT represents Fahrenheit.

Let's call this brain the Celsius-to-Fahrenheit-Converter.

As previously noted, it will have two PARAMETERS: WEIGHT and BIAS.

The brain will be just a formula like this:

OUTPUT = INPUT * WEIGHT + BIAS
Initial PARAMETERS

Suppose we don't yet know what these PARAMETERS should be, so let's start by setting them to zero:

WEIGHT = 0.0
BIAS   = 0.0

At first, the brain will generate nonsense, since with any INPUT the OUTPUT is zero.

Dataset

We have this training DATASET consisting of two EXAMPLES:

# INPUT TARGET
EXAMPLE 1 0.0 32.0
EXAMPLE 2 1.0 33.8

EXAMPLE 1 means when the INPUT is 0.0, the OUTPUT must be 32.0, because 0.0°C equals 32.0°F.

EXAMPLE 2 means when the INPUT is 1.0, the OUTPUT must be 33.8, because 1.0°C equals 33.8°F.

During TRAINING, in each LESSON, the brain changes each PARAMETER so that the OUTPUT gets closer to the TARGET.

Change Rule

The brain changes each PARAMETER using the FUNDAMENTAL CHANGE RULE:

FUNDAMENTAL CHANGE RULE for PARAMETER
PARAMETER_change = ERROR * influence_PARAMETER_OUTPUT * PACE
PARAMETER = PARAMETER + PARAMETER_change

Because the brain has two PARAMETERS — WEIGHT and BIAS — we obtain these two change rules:

FUNDAMENTAL CHANGE RULE for WEIGHT
WEIGHT_change = ERROR * influence_WEIGHT_OUTPUT * PACE
WEIGHT = WEIGHT + WEIGHT_change
FUNDAMENTAL CHANGE RULE for BIAS
BIAS_change = ERROR * influence_BIAS_OUTPUT * PACE
BIAS = BIAS + BIAS_change

Don't worry — each step is simple. Just follow the calculations below.

Training
EPOCH 1
LESSON 1
WEIGHT = 0.0
BIAS   = 0.0
PACE   = 1.0

EXAMPLE 1:

INPUT  = 0.0
TARGET = 32.0
Forward Pass
PRODUCT = INPUT * WEIGHT = 0.0 * 0.0 = 0.0
SUM = PRODUCT + BIAS = 0.0 + 0.0 = 0.0
OUTPUT = SUM = 0.0
Error
ERROR = TARGET − OUTPUT = 32.0 − 0.0 = 32.0
LOSS
LOSS = abs(ERROR) = abs(32.0) = 32.0

LOSS — abs(ERROR) — turns every ERROR into a positive number. That way, when we add up all the ERRORS across a full EPOCH, two ERRORS like -2.0 and +2.0 don't cancel each other (-2.0 + 2.0 = 0.0) to make it look like zero ERRORS were made.

total_LOSS
LOSS_contribution = LOSS / EXAMPLES = 32.0 / 2 = 16.0
total_LOSS = total_LOSS + LOSS_contribution = 0.0 + 16.0 = 16.0

LOSS_contribution is the amount of LOSS this EXAMPLE adds to the total_LOSS for this EPOCH.

LOSS is used to monitor how well the TRAINING is progressing. In a good TRAINING, the total_LOSS should decrease over the full TRAINING.

Backward Pass — Backpropagation

In this LESSON, two PARAMETERS compete for the largest CHANGE. The PARAMETER with the largest ERROR and INFLUENCE — calculated as ERROR * influence_PARAMETER_OUTPUT — receives the largest CHANGE because changing it has the greatest effect on both changing the OUTPUT and reducing the ERROR.

The core logic is simple:

high ERROR * high INFLUENCE = larger CHANGE

The PARAMETER_change is calculated exactly this way.

FUNDAMENTAL CHANGE RULE for WEIGHT
WEIGHT_change = ERROR * influence_WEIGHT_OUTPUT * PACE
WEIGHT = WEIGHT + WEIGHT_change
WEIGHT = 0.0
ERROR  = 32.0
PACE   = 1.0
CHAIN of INFLUENCES
influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_SUM
  * influence_SUM_OUTPUT
)
What is influence_WEIGHT_PRODUCT here?
Our formula is: PRODUCT = INPUT * WEIGHT
The number that multiplies the WEIGHT is INPUT.
Therefore: influence_WEIGHT_PRODUCT = INPUT 
influence_WEIGHT_PRODUCT = INPUT = 0.0
What is influence_PRODUCT_SUM here?
The formula is: SUM = PRODUCT + BIAS
We can re-write it this way: SUM = 1.0 * PRODUCT + BIAS
The number that multiplies the PRODUCT is 1.0.
Therefore: influence_PRODUCT_SUM = 1.0 
influence_PRODUCT_SUM = 1.0
What is influence_SUM_OUTPUT here?
Our formula is: OUTPUT = SUM
We can re-write it this way: OUTPUT = 1.0 * SUM
The number that multiplies the SUM is 1.0.
Therefore: influence_SUM_OUTPUT = 1.0 
influence_SUM_OUTPUT = 1.0

influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_SUM
  * influence_SUM_OUTPUT
) = (
    0.0
  * 1.0
  * 1.0
) = 0.0

WEIGHT_change = (
    ERROR
  * influence_WEIGHT_OUTPUT
  * PACE
) = (
    32.0
  * 0.0
  * 1.0
) = 0.0

WEIGHT = WEIGHT + WEIGHT_change = 0.0 + 0.0 = 0.0

BIAS = BIAS + BIAS_change

)

Our formula is: SUM = PRODUCT + BIAS

The number that multiplies the BIAS is 1.0.

Error

It has learned the rule: convert Celsius temperatures into Fahrenheit.

Note

Crucially, BIAS adds capability to the NEURON. Without BIAS, the brain would not even be able to solve a problem as simple as converting Celsius to Fahrenheit — because 0°C is 32°F, which requires adding the BIAS (32.0).

In each LESSON, all PARAMETERS compete for the largest CHANGE. The PARAMETER with the largest ERROR and INFLUENCE — calculated as ERROR * influence_PARAMETER_OUTPUT — receives the largest CHANGE because changing it has the greatest effect on both changing the OUTPUT and reducing the ERROR.

The core logic is simple:

high ERROR * high INFLUENCE = larger CHANGE

The PARAMETER_change is calculated exactly this way.

FUNDAMENTAL CHANGE RULE for PARAMETER
PARAMETER_change = ERROR * influence_PARAMETER_OUTPUT * PACE
PARAMETER = PARAMETER + PARAMETER_change

PARAMETER — This is the thing the machine is trying to get right.

PARAMETER_change — How much the PARAMETER is changed at the given LESSON.

ERROR — How wrong the machine was.

influence_PARAMETER_OUTPUT — The INFLUENCE of the PARAMETER on the OUTPUT.

PACE — A number that keeps each change from being both too big and too small.
