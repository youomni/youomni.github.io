Our educational materials are carefully designed to be clear, repetitive, and accessible for young learners. We believe that if a typical 10-year-old can easily understand an idea, most adults can too.

In this class, we add INFLUENCE to the PARAMETER CHANGE RULE.

We also introduce the CHAIN of INFLUENCES.

INFLUENCE

First, consider INFLUENCE.

To understand this simple concept, let's look at three examples, each with a simple formula.

1
Example 1

The simple formula:

RESULT = 3.0 * ELEMENT

If ELEMENT = 5.0, then RESULT = 3.0 * 5.0 = 15.0.

Now, if we change the ELEMENT by +0.1, the RESULT changes by +0.3:

ELEMENT = 5.0 + 0.1 = 5.1
RESULT = 3.0 * 5.1 = 15.3

ELEMENT_change = 5.1 − 5.0 = 0.1
RESULT_change = 15.3 − 15.0 = 0.3

MULTIPLIER = RESULT_change / ELEMENT_change = 0.3 / 0.1 = 3.0

👉 The RESULT changed 3.0 times as much as the ELEMENT.

So we say: The INFLUENCE of the ELEMENT on the RESULT is 3.0:

influence_ELEMENT_RESULT = 3.0
Takeaway
The number (3.0) that multiplies the ELEMENT is the INFLUENCE of that ELEMENT on the RESULT.

RESULT = 3.0 * ELEMENT
influence_ELEMENT_RESULT = 3.0
2
Example 2

The simple formula:

RESULT = −3.0 * ELEMENT

If ELEMENT = 5.0, then RESULT = −3.0 * 5.0 = −15.0.

Now, if we change the ELEMENT by +0.1, the RESULT changes by −0.3:

ELEMENT = 5.0 + 0.1 = 5.1
RESULT = −3.0 * 5.1 = −15.3

ELEMENT_change = 5.1 − 5.0 = 0.1
RESULT_change = −15.3 − (−15.0) = −0.3

MULTIPLIER = RESULT_change / ELEMENT_change = −0.3 / 0.1 = −3.0

👉 The RESULT changed 3.0 times as much as the ELEMENT, but in the opposite direction.

So we say: The INFLUENCE of the ELEMENT on the RESULT is −3.0.

influence_ELEMENT_RESULT = -3.0
Takeaway
The number (−3.0) that multiplies the ELEMENT is the INFLUENCE of that ELEMENT on the RESULT.

RESULT = −3.0 * ELEMENT
influence_ELEMENT_RESULT = −3.0
3
Example 3

The simple formula:

RESULT = ELEMENT

We can re-write it this way:

RESULT = 1.0 * ELEMENT

If ELEMENT = 5.0, then RESULT = 1.0 * 5.0 = 5.0.

Now, if we change the ELEMENT by +0.1, the RESULT also changes by +0.1:

ELEMENT = 5.0 + 0.1 = 5.1
RESULT = 1.0 * 5.1 = 5.1

ELEMENT_change = 5.1 − 5.0 = 0.1
RESULT_change = 5.1 − 5.0 = 0.1

MULTIPLIER = RESULT_change / ELEMENT_change = 0.1 / 0.1 = 1.0

👉 The RESULT changed by exactly the same amount as the ELEMENT. In other words, the RESULT remains equal to the ELEMENT.

So we say: The INFLUENCE of the ELEMENT on the RESULT is 1.0:

influence_ELEMENT_RESULT = 1.0
Takeaway
The number (1.0) that multiplies the ELEMENT is the INFLUENCE of that ELEMENT on the RESULT.

RESULT = 1.0 * ELEMENT
influence_ELEMENT_RESULT = 1.0

The universal takeaway for simple formulas:

Universal Takeaway
For a simple formula, the number that multiplies an ELEMENT is the INFLUENCE of that ELEMENT on the RESULT.
CHAIN of INFLUENCES

Now, consider the CHAIN of INFLUENCES.

To understand this simple concept, let's look at two examples, each with simple formulas.

1
Example 1

The simple formulas:

B = 0.8 * C
A = 0.5 * B

The INFLUENCE of C on B is 0.8:
influence_C_B = 0.8

The INFLUENCE of B on A is 0.5:
influence_B_A = 0.5

But what is the INFLUENCE of C on A?

It is simply the product of the influences along the chain:

CHAIN of INFLUENCES:

influence_C_A = (
    influence_C_B
  * influence_B_A
) = (
    0.8
  * 0.5
) = 0.4
Takeaway
To find the INFLUENCE of the initial ELEMENT (C) on the RESULT (A), we simply multiply all the INFLUENCES along the CHAIN.

In other words, when we tweak the initial ELEMENT (C), the effect on the final RESULT (A) can be determined by multiplying all the INFLUENCES along the CHAIN.

What is an ELEMENT here?

An ELEMENT is simply a number that takes part in a formula. The same ELEMENT can be the RESULT of one formula and an input ELEMENT in another formula.

2
Example 2

The simple formulas:

C = -0.9 * D
B = 0.8 * C
A = 0.5 * B

The INFLUENCE of D on C is -0.9:
influence_D_C = -0.9

The INFLUENCE of C on B is 0.8:
influence_C_B = 0.8

The INFLUENCE of B on A is 0.5:
influence_B_A = 0.5

But what is the INFLUENCE of D on A?

Again, it is the product of the influences along the chain:

CHAIN of INFLUENCES:

influence_D_A = (
    influence_D_C
  * influence_C_B
  * influence_B_A
) = (
    -0.9
  * 0.8
  * 0.5
) = -0.36
Takeaway
To find the INFLUENCE of the initial ELEMENT (D) on the RESULT (A), we simply multiply all the INFLUENCES along the CHAIN.

In other words, when we tweak the initial ELEMENT (D), the effect on the final RESULT (A) can be determined by multiplying all the INFLUENCES along the CHAIN.
The Universal Takeaway
To find the overall INFLUENCE of an initial ELEMENT on a final RESULT across multiple connected formulas, you multiply all the individual INFLUENCES along the CHAIN.
Brain

We're going to build a machine brain that can multiply any number by 5.0.

Let's call this brain the Multiplier-by-Five.

It will have a single PARAMETER: WEIGHT.

The brain will be a simple formula like this:

OUTPUT = INPUT * WEIGHT

We need to find the correct PARAMETER: WEIGHT.

Initial PARAMETER

Suppose we don't yet know what the PARAMETER should be, so let's start by setting it to zero:

WEIGHT = 0.00

At first, the brain will generate nonsense, since with any INPUT the OUTPUT is zero.

Dataset

We have this training DATASET consisting of two EXAMPLES:

INPUT TARGET
EXAMPLE 1  0.60  3.00
EXAMPLE 2 -1.00 -5.00

EXAMPLE 1 means when the INPUT is 0.60, the OUTPUT must be 3.00.
EXAMPLE 2 means when the INPUT is -1.00, the OUTPUT must be -5.00.

During TRAINING, in each LESSON, the brain changes the PARAMETER so that the OUTPUT gets closer to the TARGET.

Change Rule

The brain changes the PARAMETER using this CHANGE RULE:

SIMPLIFIED CHANGE RULE for PARAMETER
PARAMETER_change = ERROR * influence_PARAMETER_OUTPUT
PARAMETER = PARAMETER + PARAMETER_change

Because the brain has just one PARAMETER — WEIGHT — we obtain:

SIMPLIFIED CHANGE RULE for WEIGHT
WEIGHT_change = ERROR * influence_WEIGHT_OUTPUT
WEIGHT = WEIGHT + WEIGHT_change

Don't worry — each step is simple. Just follow the calculations below.

Training
LESSON 1
EXAMPLES = 2
EPOCHS   = 1
WEIGHT = 0.00

EXAMPLE 1:

INPUT  = 0.60
TARGET = 3.00
Forward Pass
PRODUCT = INPUT * WEIGHT = 0.60 * 0.00 = 0.00
OUTPUT = PRODUCT = 0.00
Error
ERROR = TARGET − OUTPUT = 3.00 − 0.00 = 3.00
Backward Pass — Backpropagation
SIMPLIFIED CHANGE RULE for WEIGHT
WEIGHT_change = ERROR * influence_WEIGHT_OUTPUT
WEIGHT = WEIGHT + WEIGHT_change
WEIGHT = 0.00
ERROR  = 3.00
CHAIN of INFLUENCES:
influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_OUTPUT
)
What is influence_WEIGHT_PRODUCT here?
The formula is: PRODUCT = INPUT * WEIGHT
The number that multiplies the WEIGHT is the INPUT.
Therefore: influence_WEIGHT_PRODUCT = INPUT 
influence_WEIGHT_PRODUCT = INPUT = 0.60
What is influence_PRODUCT_OUTPUT here?
The formula is: OUTPUT = PRODUCT
We can re-write it this way: OUTPUT = 1.00 * PRODUCT
The number that multiplies the PRODUCT is 1.00.
Therefore: influence_PRODUCT_OUTPUT = 1.00 
influence_PRODUCT_OUTPUT = 1.00

influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_OUTPUT
) = (
    0.60
  * 1.00
) = 0.60

WEIGHT_change = (
    ERROR
  * influence_WEIGHT_OUTPUT
) = (
    3.00
  * 0.60
) = 1.80

WEIGHT = WEIGHT + WEIGHT_change = 0.00 + 1.80 = 1.80
So the WEIGHT becomes 1.80. 
WEIGHT = 1.80
What just happened?

The brain has just improved itself.

Now, if it receives the same INPUT of 0.60, the OUTPUT becomes 1.08 (0.60 * 1.80) — which is closer to the TARGET (3.00) than the previous OUTPUT (0.00) was.

The ERROR becomes smaller:

ERROR = 1.92


LESSON 1 ends here.

LESSON 2

EXAMPLE 2:

INPUT  = -1.00

Backward Pass — Backpropagation
SIMPLIFIED CHANGE RULE for WEIGHT
WEIGHT_change = ERROR * influence_WEIGHT_OUTPUT
WEIGHT = WEIGHT + WEIGHT_change
WEIGHT =  1.80
ERROR  = -3.20
CHAIN of INFLUENCES:
influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_OUTPUT

What is influence_WEIGHT_PRODUCT here?
The formula is: PRODUCT = INPUT * WEIGHT
The number that multiplies the WEIGHT is the INPUT.
Therefore: influence_WEIGHT_PRODUCT = INPUT 
influence_WEIGHT_PRODUCT = INPUT = -1.00
What is influence_PRODUCT_OUTPUT here?
The formula is: OUTPUT = PRODUCT
We can re-write it this way: OUTPUT = 1.00 * PRODUCT
The number that multiplies the PRODUCT is 1.00.
Therefore: influence_PRODUCT_OUTPUT = 1.00 
influence_PRODUCT_OUTPUT = 1.00

influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT

Wait — it's not just closer. It's exact!

The OUTPUT is now -5.00 — exactly the same as the TARGET.

The ERROR becomes zero:

ERROR = 0.00


LESSON 2 ends here.

Testing

To test the brain, we give it a new EXAMPLE it has never seen before.

WEIGHT = 5.00

EXAMPLE FOR TESTING:

INPUT  = 10.00
TARGET = 50.00
Forward Pass
PRODUCT = INPUT * WEIGHT = 10.00 * 5.00 = 50.00
OUTPUT = PRODUCT = 50.00
Error
ERROR = TARGET − OUTPUT = 50.00 − 50.00 = 0.00

Since ERROR = 0.00, this brain works perfectly!

It has learned the rule: multiply any number by 5.0.

The Multiplier-by-Five can now solve problems it has never encountered before.

The brain is now just this formula:

OUTPUT = INPUT * 5.00
