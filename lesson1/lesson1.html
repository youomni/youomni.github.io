Introduction to Artificial Neurons

Artificial Neuron

An artificial neuron receives input values, applies specific mathematical weights, adds a bias term, and passes the result through an activation function.

Key Concept

Weights control the steepness of the signal transfer, while bias shifts the activation threshold horizontally across the input space.

Mathematical Formula

OUTPUT = ACTIVATION( SUM( WEIGHTS * INPUTS ) + BIAS )
