HOW MACHINES LEARN AND THINK
Lesson 3
PACE
Introduction

In this Lesson, we introduce the Pace of Learning — or PACE for short.

PACE is just a number that keeps each change from being both too big and too small.

By adding PACE to our PARAMETER CHANGE RULE, we help the brain learn smoothly and steadily.

For example, let's set it to 0.0100:

PACE = 0.0100
Brain

We're going to build a machine brain that can multiply any number by 5.0000.

Let's call this brain the Multiplier-by-Five.

It will have a single PARAMETER: WEIGHT.

The brain will be a simple formula like this:

OUTPUT = INPUT * WEIGHT

We need to find the correct PARAMETER: WEIGHT.

Initial PARAMETER

Suppose we don't yet know what the PARAMETER should be, so let's start by setting it to zero:

WEIGHT = 0.0000

At first, the brain will generate nonsense, since with any INPUT the OUTPUT is zero.

Dataset

We have this training DATASET consisting of two EXAMPLES:

INPUT TARGET
EXAMPLE 1  0.6000  3.0000
EXAMPLE 2 -10.0000 -50.0000

EXAMPLE 1 means when the INPUT is 0.6000, the OUTPUT must be 3.0000.
EXAMPLE 2 means when the INPUT is -10.0000, the OUTPUT must be -50.0000.

During TRAINING, in each LESSON, the brain changes the PARAMETER so that the OUTPUT gets closer to the TARGET.

Change Rule

The brain changes the PARAMETER using the FUNDAMENTAL CHANGE RULE:

FUNDAMENTAL CHANGE RULE for PARAMETER
PARAMETER_change = ERROR * influence_PARAMETER_OUTPUT * PACE
PARAMETER = PARAMETER + PARAMETER_change

Because the brain has just one PARAMETER — WEIGHT — we obtain:

FUNDAMENTAL CHANGE RULE for WEIGHT
WEIGHT_change = ERROR * influence_WEIGHT_OUTPUT * PACE
WEIGHT = WEIGHT + WEIGHT_change

Don't worry — each step is simple. Just follow the calculations below.

Training
LESSON 1
EXAMPLES = 2
EPOCHS   = 1
PACE     = 0.0100
WEIGHT = 0.0000

EXAMPLE 1:

INPUT  = 0.6000
TARGET = 3.0000
Forward Pass
PRODUCT = INPUT * WEIGHT = 0.6000 * 0.0000 = 0.0000
OUTPUT = PRODUCT = 0.0000
Error
ERROR = TARGET − OUTPUT = 3.0000 − 0.0000 = 3.0000
Backward Pass — Backpropagation
FUNDAMENTAL CHANGE RULE for WEIGHT
WEIGHT_change = ERROR * influence_WEIGHT_OUTPUT * PACE
WEIGHT = WEIGHT + WEIGHT_change
WEIGHT = 0.0000
ERROR  = 3.0000
PACE   = 0.0100
CHAIN of INFLUENCES:
influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_OUTPUT
)
What is influence_WEIGHT_PRODUCT here?
The formula is: PRODUCT = INPUT * WEIGHT
The number that multiplies the WEIGHT is the INPUT.
Therefore: influence_WEIGHT_PRODUCT = INPUT 
influence_WEIGHT_PRODUCT = INPUT = 0.6000
What is influence_PRODUCT_OUTPUT here?
The formula is: OUTPUT = PRODUCT
We can re-write it this way: OUTPUT = 1.0000 * PRODUCT
The number that multiplies the PRODUCT is 1.0000.
Therefore: influence_PRODUCT_OUTPUT = 1.0000 
influence_PRODUCT_OUTPUT = 1.0000

influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_OUTPUT
) = (
    0.6000
  * 1.0000
) = 0.6000

WEIGHT_change = (
    ERROR
  * influence_WEIGHT_OUTPUT
  * PACE
) = (
    3.0000
  * 0.6000
  * 0.0100
) = 0.0180

WEIGHT = WEIGHT + WEIGHT_change = 0.0000 + 0.0180 = 0.0180
WEIGHT = 0.0180
What just happened?

The brain has just improved itself.

Now, if it receives the same INPUT of 0.6000, the OUTPUT becomes 0.0108 (0.6000 * 0.0180) — which is closer to the TARGET (3.0000) than the previous OUTPUT (0.0000) was.

The ERROR becomes smaller:

ERROR = 2.9892


LESSON 1 ends here.

EPOCHS   = 1

TARGET = -50.0000
Forward Pass
PRODUCT = INPUT * WEIGHT = -10.0000 * 0.0180 = -0.1800
OUTPUT = PRODUCT = -0.1800
Error
ERROR = TARGET − OUTPUT = -50.0000 − (−0.1800) = -49.8200
Backward Pass — Backpropagation
FUNDAMENTAL CHANGE RULE for WEIGHT
WEIGHT_change = ERROR * influence_WEIGHT_OUTPUT * PACE
WEIGHT = WEIGHT + WEIGHT_change
WEIGHT =   0.0180
ERROR  = -49.8200
PACE   =   0.0100
CHAIN of INFLUENCES:
influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_OUTPUT
)
What is influence_WEIGHT_PRODUCT here?
The formula is: PRODUCT = INPUT * WEIGHT
The number that multiplies the WEIGHT is the INPUT.
Therefore: influence_WEIGHT_PRODUCT = INPUT 
influence_WEIGHT_PRODUCT = INPUT = -10.0000
What is influence_PRODUCT_OUTPUT here?
The formula is: OUTPUT = PRODUCT
We can re-write it this way: OUTPUT = 1.0000 * PRODUCT
The number that multiplies the PRODUCT is 1.0000.
Therefore: influence_PRODUCT_OUTPUT = 1.0000 
influence_PRODUCT_OUTPUT = 1.0000

influence_WEIGHT_OUTPUT = (
    influence_WEIGHT_PRODUCT
  * influence_PRODUCT_OUTPUT
) = (
    -10.0000
  *   1.0000
) = -10.0000

WEIGHT_change = (
    ERROR
  * influence_WEIGHT_OUTPUT
  * PACE
) = (
    -49.8200
  * -10.0000
  *   0.0100
) =   4.9820

WEIGHT = WEIGHT + WEIGHT_change = 0.0180 + 4.9820 = 5.0000
WEIGHT = 5.0000
What just happened?

The brain has just improved itself again.

Now, if it receives the same INPUT of −10.0000, the OUTPUT becomes −50.0000 (−10.0000 * 5.0000) — which is closer to the TARGET (−50.0000) than the previous OUTPUT (-0.1800) was.

Wait — it's not just closer. It's exact!

The OUTPUT is now -50.0000 — exactly the same as the TARGET.

The ERROR becomes zero:

ERROR = 0.0000


LESSON 2 ends here.

WEIGHT = 5.0000

EXAMPLE for TESTING:

INPUT  = 10.0000
TARGET = 50.0000
Forward Pass
PRODUCT = INPUT * WEIGHT = 10.0000 * 5.0000 = 50.0000
OUTPUT = PRODUCT = 50.0000
Error
ERROR = TARGET − OUTPUT = 50.0000 − 50.0000 = 0.0000

Since ERROR = 0.0000, this brain works perfectly!

It has learned the rule: multiply any number by 5.0.

The Multiplier-By-Five can now solve problems it has never encountered before.

The brain is now just this formula:

OUTPUT = INPUT * 5.0000

Note

Lesson 3 clearly shows why we need PACE. Without it, that LESSON 2 change would have been 498.2, causing the WEIGHT to shoot too high.

By keeping the PACE at 0.0100, you are effectively telling the machine: "I know you found an error, but don't try to fix it all at once; just take a small step in the right direction." The PACE, together with the ERROR and INFLUENCE, helps the WEIGHT reach exactly 5.0000.

On the other hand, when PACE is too small — say, 0.000001 — then LEARNING becomes very slow and can take a long time.

Therefore, PACE keeps each change from being both too big and too small.

Metaphorically, the "villain" is exploding changes, and the hero is PACE, which keeps LEARNING stable.

So, we finally arrive at the FUNDAMENTAL CHANGE RULE:

FUNDAMENTAL CHANGE RULE for PARAMETER
PARAMETER_change = ERROR * influence_PARAMETER_OUTPUT * PACE
PARAMETER = PARAMETER + PARAMETER_change

PARAMETER — This is the thing the machine is trying to get right.

PARAMETER_change — How much the PARAMETER is changed at the given LESSON.

ERROR — How wrong the machine was.

influence_PARAMETER_OUTPUT — The INFLUENCE of the PARAMETER on the OUTPUT.

PACE — A number that keeps each change from being both too big and too small.
